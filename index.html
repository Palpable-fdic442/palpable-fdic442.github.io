📝 Setup Notes

Here are some helpful notes we've compiled from previous setups. Keep these in mind as you get started:

  • Default Installation Path: The installer will suggest C:\Program Files\BFD3. You can change this if you prefer a different location.
  • Session Logs: BFD3 automatically saves session logs to %USERPROFILE%\Documents\BFD3\Logs. These logs help you track your activity and troubleshoot issues.
  • Workflow Templates: The application includes several pre-built templates to help you get started quickly. You can access them from the "File" menu.
  • Updates: BFD3 will check for updates automatically. You can also manually check for updates from the "Help" menu.
  • Firewall/Antivirus: Some security software may flag the installer. This is a false positive; you can safely allow the installation.

🔧 Troubleshooting

If you encounter any problems, try these common solutions:

  • Installation fails: Make sure you have administrator privileges. Right-click the installer and select "Run as administrator".
  • App won't launch: Check that your antivirus isn't blocking the application. Add an exception for BFD3 if needed.
  • Session logs not saving: Verify that the logs folder exists and is writable. You can manually create the folder at the path mentioned above.
  • General errors: Restart your computer and try again. Many issues are resolved with a simple reboot.

📅 Session Logs

Session logs are automatically created every time you use BFD3. These logs contain timestamps, actions performed, and any errors encountered. They are invaluable for debugging and tracking your progress. To view your logs:

  1. Open File Explorer and navigate to %USERPROFILE%\Documents\BFD3\Logs.
  2. Look for files named like session-2026-01-01.log.
  3. Open any log file with Notepad or a text editor to review its contents.

If you encounter an issue, checking the session log is the first step to understanding what went wrong.
